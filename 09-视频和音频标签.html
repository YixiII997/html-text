视频标签

视频标签 video 是一个单标签 或者 空元素

src 视频路径

width height 视频的宽度和高度

controls 视频是否显示控制 默认不显示

autoplay 视频是否自动播放 默认不自动播放

loop 视频是否循环播放视频 默认不循环播放

muted 视频是否静音播放 默认不静音

poster 视频封面 默认不显示封面

在h5中 如果 属性的键和值是相同的 则可以省略值 例如 controls="controls"代表着打开网页控制 可以写成 controls 如果想要关闭 写成 controls=false

视频兼容性

mp4 视频格式 支持所有浏览器 插入视频的时候优先考虑

webm和ogg 视频格式 IE和Safari不支持

这个时候就需要兼容性写法 在video标签中嵌套source标签

浏览器会寻找第一个兼容的视频格式 并且播放 不执行下面的代码

source标签的属性 src 视频路径 type 视频格式

type 视频格式 不要省略 可以帮助浏览器快速省略不支持的类型 不然会占用大量时间

type的值 可以是 video/mp4 video/webm video/ogg
