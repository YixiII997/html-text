表单（input的文本框和密码框）

场景 用户注册 搜索框 问卷 文件上传 支付

表单的组成

组成 标签名 属性 作用
表单容器 form action 用于包裹所有表单控件 是一个区域 用于收集区域里的所有数据
表单控件 input输入框 textarea多行文本输入框 select下拉选择框 button按钮等 和用户交互
辅助标签 label关联标签 用于提高用户体验

表单容器 form

双标签 用于定义表单容器 包裹所有控件

属性 action="" 定义了 在提交表单的时候 把收集的数据 给某个地方 的 url地址

input 表单

创建 输入框 密码框 单选框 复选框等等

input的属性 属性值 作用 其他属性 概念
type text 单行文本框 placeholder提示信息 有内容不会显示 只能在单行输入文本
name 元素的名称
maxlength 允许的最大字符数量
accsesskey 使元素获得焦点的快捷键 设置后用 alt+设置的快捷键 就可以定位焦点 (windows 用alt＋键||mac 用ctrl+option+键)
autocomplete 是否根据用户历史信息自动填充 值为 on（是）/off （否） 在正常情况下 敏感信息设为off 默认是打开的on
password 密码框 和text相同 密文显示

练习区

  • 单行文本框 type="text"
  • 密码框 type="password"
