表单（input单选框，复选框，文件域）

单选框和复选框

radio单选框 checkbox复选框

input的属性 属性值 作用 其他属性 概念
type radio 单选框 name 表单名称 实现分组 在相同的name的单选框中 只能选中 一个单选框
value 表单值
checked 是否默认选中 checked="checked" 页面打开时候 该单选框自动选择
但是如果一个name中 有多个checked 默认最后一个生效
checkbox 复选框 和radio 单选框 相同
file 文件域
上传文件 		multiple 允许选择多个文件 如果不写 默认是选择一个
accept 规定选择的文件类型 多个类型用逗号分隔

练习区

  • 单选框 type="radio" name相同分组↓
    第一个单选框 第二个单选框
  • 复选框 type="checkbox"
    第一个复选框 第二个复选框 第三个复选框
  • 文件域 file
    可以选择多个文件 multiple
    accept=".mp4,.jpg" accept规定了上传mp4 和 jpg文件类型
