多行文本输入框，下拉表单控件，按钮

多行文本输入框

input的属性 属性值 作用 其他属性 概念
type textarea 多行文本输入框 name 表单名称
placeholder 提示信息
rows 文本行数 正整数 默认为2 一般通过css修改
cols 文本列数 正整数 默认为20 一般通过css修改

下拉表单控件

input的属性 属性值 属性概念 属性组成标签 属性 作用
type select 下拉表单控件 select name 表单名称
option value 每个选项对应的值
selected 可以设置默认选中的项

按钮控件

input的属性 属性值 作用 其他属性 概念
type button 按钮控件 disabied disabled="disabled"按钮被禁用
