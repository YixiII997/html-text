css选择器（类型选择器）

选择器的概念

选择指定html元素的方式

如 p { font-size:18px } 其中 p是选择器 font-size是属性名 18px是属性值

选择器的分类

分类 常用的分类 作用以及代码结构
基础选择器 类型选择器 || 标签选择器 把html标签名作为选择器
类选择器
id选择器
通配符选择器

如果给同一个选择器加了不同的样式 选择后者

就近原则 或者 层叠性 覆盖性

解决了冲突的问题

代码规范性

  • 选择器和代码中间有一个空格
  • 属性名 和属性值之间 也保留一个空格
  • 每个css属性独占一行 后期打包压缩再说
  • css注释要 /* 前后都保留一个空格 */
